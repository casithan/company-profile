Mengapa Memilih Jurusan TKJ?

Di era transformasi digital, hampir seluruh sektor bisnis, pemerintahan, dan pendidikan bergantung pada konektivitas internet dan pusat data (data center). Jurusan TKJ membekali siswa dengan kombinasi kemampuan praktik perangkat keras (hardware), konfigurasi jaringan, serta administrasi sistem server.

  • ✓ 70% Praktik, 30% Teori: Pembelajaran berbasis proyek nyata di laboratorium berstandar industri.
  • ✓ Sertifikasi Kompetensi: Uji kompetensi keahlian (UKK) bersama asesor BNSP dan vendor jaringan.
  • ✓ Teaching Factory (TeFa): Siswa mengelola jaringan internet sekolah dan layanan perbaikan IT secara profesional.

Menjadi pusat unggulan pendidikan vokasi bidang infrastruktur jaringan dan teknologi cloud yang adaptif, berkarakter, dan berdaya saing global.

// Infrastruktur Belajar

Fasilitas Laboratorium TKJ

Setiap laboratorium dilengkapi perangkat keras aktual agar siswa terbiasa dengan lingkungan kerja sesungguhnya.

LAB 01

Lab Routing & Switching

Dilengkapi puluhan unit RouterBoard MikroTik, Cisco Catalyst Switch, dan rak server simulasi topologi WAN.

LAB 02

Lab Fiber Optic & FTTH

Perangkat Fusion Splicer, OTDR, OPM, OLT, dan ONT untuk simulasi instalasi jaringan internet fiber ke rumah.

LAB 03

Lab Server & Cloud

Server Rackmount Dell PowerEdge untuk praktik virtualisasi Proxmox, Linux Server, Docker, dan hosting web.

LAB 04

Workshop Hardware & IoT

Area perakitan PC, troubleshooting perangkat keras, solder station, serta pengembangan mikrokontroler IoT.

// Masa Depan Lulusan

Prospek Karir Lulusan TKJ

Lulusan memiliki fleksibilitas tinggi untuk langsung bekerja, berwirausaha di bidang IT, maupun melanjutkan kuliah.

NE

Network Engineer

Merancang, membangun, dan memelihara infrastruktur jaringan skala perusahaan maupun ISP.

SA

System Administrator

Mengelola server Linux/Windows, database, layanan cloud, dan virtualisasi data center.

IT

IT Support Specialist

Menangani pemeliharaan perangkat keras, sistem operasi, serta dukungan teknis operasional.

FO

Fiber Optic Technician

Instalasi, penyambungan (splicing), dan pemeliharaan jaringan tulang punggung serat optik.

CS

Junior Cyber Security Analyst

Memantau keamanan lalu lintas jaringan, konfigurasi firewall, dan mitigasi serangan siber.

EN

Technopreneur IT

Membuka jasa layanan internet RT/RW Net resmi, konsultan jaringan, atau servis komputer.
